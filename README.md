## Обо мне

Проектирую и разрабатываю веб-продукты целиком: от структуры и интерфейса до интеграций, деплоя и поддержки. Сложную логику превращаю в понятные интерфейсы.

- **3+ года** коммерческой разработки, **90+** запущенных веб-проектов
- Frontend-архитектура на **React 19 / Next.js 16 / TypeScript** — SSR, RSC, дизайн-система, Storybook
- Backend-часть и данные: **Node.js, PHP, Prisma / Drizzle, PostgreSQL, MySQL**
- Интеграции: **REST API, вебхуки, CRM (amoCRM, Bitrix24), платежи, аналитика**
- Люблю выразительный фронтенд: анимация, **WebGL / three.js**, интерфейсы с характером
